# Тестовая дисциплина в omp-plan-kit

1. **Размещение**:
   - Все тесты лежат **только в `tests/`** (`tests/e2e-*.mjs`, `tests/*.test.ts`).
   - В `scripts/` находятся исключительно сценарии установки и управления (`install-all-profiles.mjs`, `uninstall-all-profiles.mjs`). Никаких тестов в `scripts/`.
   - Любой новый тест обязательно регистрируется в `package.json#scripts` (`check` и соответствующие `e2e:*`).

2. **Честность и полнота проверок**:
   - Запрещены фиктивные проверки, где целевой код не вызывался или счётчик реальных вызовов равен нулю.
   - Тест обязан проверять обе ветки: негативную (блокировка/ошибка) и позитивную (успешный сквозной проход).
   - Все временные файлы и песочницы сессий (`omp-local`, `omp-plan-*`) обязаны очищаться в блоке `finally`.

3. **Запуск и Windows-совместимость**:
   - Не использовать двоеточия в аргументах CLI-команд (например, `bun run e2e:all`), чтобы не триггерить ложные срабатывания защиты путей на Windows (Alternate Data Streams). Запускать файлы напрямую: `bun tests/e2e-....mjs`.
   - Проверять запуск тестов через `node --check` в общем пайплайне `npm run check`.
